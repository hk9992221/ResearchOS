## Highlights

ResearchOS 1.0.2 restores two rendering paths that failed silently in the desktop app.

- **Scanned PDF backdrops render again:** pdf.js 6 decodes JBIG2 / JPEG 2000 scans with WebAssembly modules and loads CMaps as separate static files. The renderer now ships and serves them under `pdfjs/wasm/` and `pdfjs/cmaps/`, passes `wasmUrl` / `cMapUrl` / `cMapPacked` to `getDocument`, and allows `'wasm-unsafe-eval'` in the Content-Security-Policy so Chromium can compile the decoders. Before this, scanned pages showed only the OCR text layer on a blank canvas.
- **Plugin panels load their modules:** `plugin://` assets now return `Access-Control-Allow-Origin` and the scheme is registered with `corsEnabled`, so `<script type="module">` inside the sandboxed panel iframe is no longer blocked cross-origin.
- **Consistent version metadata:** align all workspace packages at 1.0.2.

## Distribution notes

Windows packages are not Authenticode-signed. macOS packages are not Apple Developer ID notarized; operating-system security prompts may apply.
