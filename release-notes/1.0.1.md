## Highlights

ResearchOS 1.0.1 is a maintenance release focused on Electron IPC command registration.

- **Restore command registration:** remove a duplicated plugin host context command entry so that subsequent channels can register.
- **Defensive startup behavior:** deduplicate channel names before registering Electron IPC handlers.
- **Consistent version metadata:** align all workspace packages at 1.0.1.

## Distribution notes

Windows packages are not Authenticode-signed. macOS packages are not Apple Developer ID notarized; operating-system security prompts may apply.
